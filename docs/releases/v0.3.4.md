Add explicit unsigned development updates with the normal `agx` executable:

```sh
agx update-pre --check
agx update-pre
agx update rollback
```

- Discover the highest eligible GitHub development prerelease for the current Apple Silicon/Intel Mac or Linux x86_64 architecture. Accept stable-looking version tags marked prerelease; exclude drafts and signed releases/betas with DMGs.
- Download the native archive using verified HTTPS, exact repository URLs, GitHub SHA-256 and size verification. Bound downloads/extraction and reject traversal, links, special files, foreign roots and duplicate/missing binaries.
- Verify the staged executable's version before atomic replacement, share the existing updater lock, and retain exact hash-checked rollback. Never reinstall the same version or downgrade; never invoke sudo.
- Keep signed installation and automatic updates behind the existing Apple Team ID, signature, DMG and notarization requirements. Unsigned updates require the explicit `update-pre` command and never become scheduled jobs.
- Add native regressions for development channel/architecture selection, integrity/metadata failures, unsafe archives, PAX metadata, version mismatch, no downgrade, atomic replacement/rollback and CLI separation. Close staged writable descriptors before execution, including on Linux.

This development path trusts GitHub HTTPS/digests and does not verify Apple signatures/notarization. It updates only the binary; documentation, installer receipts and installed skill copies are not refreshed. GitHub API access is required for discovery. Older binaries need the GitHub installer once to acquire `update-pre`.
