Install the prebuilt `agx` with a GitHub-hosted POSIX shell script:

```sh
curl -fsSL https://raw.githubusercontent.com/ar4ft/agentgrep/main/scripts/install.sh | sh
```

- Install the native Apple Silicon/Intel Mac or Linux x86_64 executable under `~/.agx/bin/agx`, with documentation and the agent skill under `~/.agx/share`.
- Verify archive SHA-256, reject unsafe archives, preserve a previous binary, and replace the executable atomically. Support version pins, custom directories, optional PATH setup, and repeat installs.
- Default to the newest published release, including development prereleases, with a visible warning. `--stable` requires a production release. No Rust, sudo, model downloads, harness changes, or automatic update activation.
- Upload `install.sh` automatically with each release and include it in `SHA256SUMS`. Extend the nain adapter example's executable discovery to `~/.agx/bin/agx`; current nain still requires a native panel implementation.
- Exercise the piped installer with real native binaries in Linux, Apple Silicon, and Intel CI, including integrity failures, traversal/links, profile preservation, quoting, version pins, and lock conflicts.

The bootstrap installer trusts GitHub HTTPS and same-release checksums; it does not perform the existing updater's Apple identity/notarization verification. Ordinary tag releases remain unsigned development prereleases. Signing/notarization is enabled only by a manual release action with configured Apple credentials and `sign_and_notarize=true`.
