First working release of agentgrep (`agx`), a native local search tool for coding agents.

- Exact regex/literal search, syntax context for Rust/Python/TS/JS/Go/Swift, ranked BM25 discovery, and optional local Ollama embeddings.
- JSON source evidence with line ranges, source-byte limits, and explicit omissions.
- Stdio MCP tools plus skills for Codex and Claude Code.
- Optional local LiteParse document extraction.

Artifacts include native archives for Apple Silicon Mac, Intel Mac, and Linux x86_64, source archives, and SHA-256 checksums. Each native archive contains `agx`, documentation, the bundled skill, and build metadata.

Extract the archive matching your architecture, add `agx` to your PATH, and run `agx doctor`. Run `agx skill --harness both` in your project to install the skills. README includes MCP setup commands.

This is a prerelease. Mac binaries are unsigned and not notarized. The test suite and adapter fixtures run on each platform; real Codex/Claude task outcomes and real embedding-model retrieval quality have not been evaluated. BM25 is lexical, budgets bound source bytes rather than tokens/total JSON, and document citations refer to extracted Markdown lines.
